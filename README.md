# Ryzyko Deszczu Powraca
Nieoficajalne spolszczenie do Risk of Rain Returns. Projekt jest robiony przed jedną osobę (Hiii) bez żadnego harmonogramu.

### Wersje
- `polish` - normalna wersja spolszczenia
- `polish_desc` - wersja z opisami przedmiotów podczas gry 

### Stan tłumaczenia na 2026/03/21:
- **drony, skrzynki i inne przedmioty na mapie**: funkcjonalne
- **hud, menu główne, menu postaci, kooperacja**: funkcjonalne
- **postacie**: funkcjonalne. Brakuje opisów i wpisów z dziennika.
- **ustawienia**: funkcjonalne.
- **przedmioty**: funkcjonalne, ale wymagają poprawek. Brakuje wpisów z dziennika i bezużytecznych teksów z normalnej wersji tłumaczenia.
- **przeciwnicy**: funkcjonalne. Brakuje wpisów z dziennika.

- **wyzwanie Providence**: brak
- **wyzwanie ogólne**: brak

### "Instalacja" tłumaczenia
1. Pobierz wybraną wersję tłumaczenia
2. Skopiuj go to folderu `\language` w plikach lokalnych gry (domyślnie `C:\Program Files (x86)\Steam\steamapps\common\Risk of Rain Returns\language`)
3. Wejdź do gry i wybierz język z menu w prawym górnym rogu

LUB

Jeżeli masz Git na komputerze, sklonuj repozytorium bezpośrednio do folderu `\language`
